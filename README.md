# POPOVICHFIT — главная для Тильды (popovichfit.ru)

Две версии главной: **продажи открыты** и **продажи закрыты**. Шапка и подвал — с Тильды, в блоках их нет

## Вставка на Тильду
На странице три блока T123 (HTML-код) подряд, между шапкой и подвалом Тильды:

| Блок | Файл | Что внутри |
|---|---|---|
| 1 | `tilda/<open или closed>/1-css.html` | стили и подгрузка шрифтов |
| 2 | `tilda/<open или closed>/2-html.html` | разметка страницы, модальные окна, нижняя панель на телефоне |
| 3 | `tilda/<open или closed>/3-js.html` | скрипт: модалки, видео, карусель, появление при прокрутке |

Блоки 1 и 3 у обеих версий одинаковые — при переключении «продажи открыты ↔ закрыты» достаточно заменить блок 2

Картинки и шрифты отдаёт jsDelivr из этого репозитория (адрес закреплён на коммите, кеш не мешает)

## Превью
GitHub Pages: https://elenasamanchuk.github.io/popovichfit-home-tilda/ — блоки вставлены так же, как на Тильде, с имитацией её глобальных стилей

## Сборка
```
npm i
node scripts/build-tilda.mjs --base=https://cdn.jsdelivr.net/gh/ElenaSamanchuk/popovichfit-home-tilda@<коммит>/assets/
```
Новые исходники — в `source/` (`home-sales-open.html`, `home-sales-closed.html`, `img/`, `fonts/`). Для локального превью — `--base=../assets/`

Что делает сборка:
- вырезает шапку, мобильное меню и подвал (на Тильде свои); ссылку `/new/` (на сайте 404) не пропускает
- все селекторы под обёрткой `.pfh`, `html/body/:root` → `.pfh`, чтобы стили Тильды и страницы не мешали друг другу
- JS в IIFE без глобальных переменных, всё минифицировано esbuild
- типографика: неразрывный пробел после предлогов/союзов и перед тире, последнее слово не остаётся одно в строке, без точек в конце абзацев
- картинки в WebP (jpg → WebP q86), имена с хешем содержимого; первый экран без lazy, остальные lazy
- якоря `#courses`, `#next` с отступом под фиксированную шапку Тильды
